# Git 提交信息规则

## 格式
第一行为标题行，空一行后接详细内容。

```
X.Y <type>: <简短描述>

## 概述
<本次提交的核心目标与背景，1-3 句话概括>

## 新增资产与功能
- <具体新增的功能或资产描述>
- <每条用 "- " 开头>

## 改动文件
- <文件路径>: <改动说明>
- <每条文件改动用 "- " 开头>

## 验证（可选）
- <验证方式与结果>
```

## 规范
- vX.Y: 对应开发阶段的版本号（如 v10.9、v10.8、v10.7）
- type: feat / fix / refactor / chore 等标准 Conventional Commits 类型
- 描述使用中文，简洁准确
- 独立的功能点用 "- " 列表，多级用缩进
- 文件改动与说明之间用 ": " 分隔
